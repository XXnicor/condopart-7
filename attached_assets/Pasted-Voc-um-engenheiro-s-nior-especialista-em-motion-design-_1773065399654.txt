O PROBLEMA — ENTENDA ANTES DE CODAR
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

O que está acontecendo hoje:
1. Usuário toca em um card ou botão
2. React desmonta a tela atual instantaneamente
3. Monta a nova tela instantaneamente
4. Resultado: teleporte visual — sem contexto de onde veio
   ou para onde foi

O que deve acontecer (padrão nativo):
1. Usuário toca
2. Tela atual faz exit animation (fade out + leve slide)
3. Nova tela entra com enter animation (fade in + leve slide)
4. Resultado: o usuário entende a hierarquia de navegação

PASSO 1 — SISTEMA DE TRANSIÇÕES GLOBAL
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Crie src/components/PageTransition.tsx:

  import { motion, AnimatePresence } from 'framer-motion'
  import { ReactNode } from 'react'

  // Variantes por tipo de navegação
  const variants = {
    // Entrar numa página de detalhe (avançar)
    forward: {
      initial:  { opacity: 0, x: 24, scale: 0.99 },
      animate:  { opacity: 1, x: 0,  scale: 1    },
      exit:     { opacity: 0, x: -24, scale: 0.99 }
    },
    // Voltar para página anterior
    back: {
      initial:  { opacity: 0, x: -24, scale: 0.99 },
      animate:  { opacity: 1, x: 0,   scale: 1    },
      exit:     { opacity: 0, x: 24,  scale: 0.99 }
    },
    // Trocar de aba (BottomNav)
    tab: {
      initial:  { opacity: 0, y: 8, scale: 0.98 },
      animate:  { opacity: 1, y: 0, scale: 1    },
      exit:     { opacity: 0, y: 8, scale: 0.98 }
    },
    // Modal / bottom sheet
    modal: {
      initial:  { opacity: 0, y: 32, scale: 0.97 },
      animate:  { opacity: 1, y: 0,  scale: 1    },
      exit:     { opacity: 0, y: 32, scale: 0.97 }
    }
  }

  // Transição padrão — suave e natural
  const transition = {
    duration: 0.22,
    ease: [0.25, 0.46, 0.45, 0.94] // ease-out cubic — sensação nativa
  }

  interface PageTransitionProps {
    children: ReactNode
    type?: keyof typeof variants
    id?: string // usar a rota atual como key
  }

  export default function PageTransition({ 
    children, 
    type = 'forward',
    id 
  }: PageTransitionProps) {
    return (
      <motion.div
        key={id}
        variants={variants[type]}
        initial="initial"
        animate="animate"
        exit="exit"
        transition={transition}
        style={{ willChange: 'transform, opacity' }}
        className="w-full min-h-screen"
      >
        {children}
      </motion.div>
    )
  }

No arquivo de rotas (App.tsx ou Router.tsx), envolva as
rotas com AnimatePresence para que o exit animation
rode antes da nova tela entrar:

  import { AnimatePresence } from 'framer-motion'
  import { useLocation } from 'react-router-dom'

  function AppRoutes() {
    const location = useLocation()

    return (
      // mode="wait" — CRÍTICO: espera o exit antes do enter
      // initial={false} — não animar no primeiro carregamento
      <AnimatePresence mode="wait" initial={false}>
        <Routes location={location} key={location.pathname}>

          {/* Rotas de tab — usam variante "tab" */}
          <Route path="/" element={
            <ProtectedRoute>
              <PageTransition type="tab" id="home">
                <FeedPage />
              </PageTransition>
            </ProtectedRoute>
          } />

          <Route path="/profile" element={
            <ProtectedRoute>
              <PageTransition type="tab" id="profile">
                <ProfilePage />
              </PageTransition>
            </ProtectedRoute>
          } />

          {/* Rotas de detalhe — usam variante "forward" */}
          <Route path="/alert/:id" element={
            <ProtectedRoute>
              <PageTransition type="forward" id="alert-detail">
                <AlertDetailPage />
              </PageTransition>
            </ProtectedRoute>
          } />

          <Route path="/create-alert" element={
            <ProtectedRoute>
              <PageTransition type="forward" id="create-alert">
                <CreateAlertPage />
              </PageTransition>
            </ProtectedRoute>
          } />

          {/* Auth — fade simples */}
          <Route path="/auth" element={
            <PageTransition type="tab" id="auth">
              <AuthPage />
            </PageTransition>
          } />

          <Route path="/condo-selection" element={
            <PageTransition type="forward" id="condo-selection">
              <CondoSelectionPage />
            </PageTransition>
          } />

        </Routes>
      </AnimatePresence>
    )
  }

Dentro de cada página, o conteúdo entra em stagger
— cada seção aparece em sequência, não tudo de uma vez.

Crie src/components/FadeIn.tsx — wrapper reutilizável:

  import { motion } from 'framer-motion'
  import { ReactNode } from 'react'

  interface FadeInProps {
    children: ReactNode
    delay?: number
    className?: string
  }

  export default function FadeIn({ 
    children, 
    delay = 0,
    className 
  }: FadeInProps) {
    return (
      <motion.div
        initial={{ opacity: 0, y: 10 }}
        animate={{ opacity: 1, y: 0 }}
        transition={{
          duration: 0.2,
          delay,
          ease: [0.25, 0.46, 0.45, 0.94]
        }}
        className={className}
      >
        {children}
      </motion.div>
    )
  }

Para garantir que as animações rodam a 60fps no mobile:

No globals.css, adicione:

  /* Promover elementos animados para GPU layer */
  .page-transition {
    will-change: transform, opacity;
    transform: translateZ(0);
    backface-visibility: hidden;
  }

  /* Desativar animações para usuários que preferem */
  @media (prefers-reduced-motion: reduce) {
    * {
      animation-duration: 0.01ms !important;
      transition-duration: 0.01ms !important;
    }
  }

  /* Scroll suave global */
  html {
    scroll-behavior: smooth;
    -webkit-overflow-scrolling: touch;
  }

  /* Evitar highlight azul no toque mobile */
  * {
    -webkit-tap-highlight-color: transparent;
    touch-action: manipulation;
  }
