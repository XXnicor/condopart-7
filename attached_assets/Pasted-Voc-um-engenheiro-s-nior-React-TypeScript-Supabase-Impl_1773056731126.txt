      role
    )
  `)

Ajuste o tipo TypeScript do retorno para incluir:
  profiles: {
    full_name: string
    avatar_url: string | null
    role: string

### 2. Query do detalhe (/alert/:id)

Ajuste o tipo da mesma forma.

- role (ou "Morador" como fallback) em text-xs text-stone-400
